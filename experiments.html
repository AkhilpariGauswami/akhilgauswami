Plutus Bank

Paused
Fintech / Web3 / Core Banking

A prototype for a decentralised core banking ledger, aiming to bridge traditional fiat operations with smart contract execution. Built to test the latency and finality of cross-chain settlements.

Rust Solidity PostgreSQL
What I Learned

"The hardest part isn't the cryptography; it's state management between synchronous legacy systems and asynchronous blockchain layers. Handling edge cases in finality reversal was a major architectural headache."

Paused after reaching the cross-chain settlement prototype stage. The state management complexity required more time than the experiment warranted at that point.

Hands of Cards

Ongoing
Game Design / State Machines

An engine for simulating complex card game mechanics and evaluating probability matrices. Currently focusing on building a deterministic state machine for resolving simultaneous card effects.

TypeScript XState Canvas API
What I Learned

"Modelling 'interrupts' in a turn-based system requires a robust stack architecture. Abstracting game rules from the UI rendering loop improved performance dramatically and made the logic testable in isolation."

The biggest insight: card game logic is a state machine problem, not a rendering problem. Separating the two made everything simpler.

Concept

These aren't projects. They're questions. Each one started as a "what if" that I couldn't stop thinking about. Some may become projects. Some may stay questions forever.

Sanskrit Programming Language

Concept
Language Design / Parser / Linguistics
What I'm Figuring Out

"How can the strict grammatical rules of Panini's Ashtadhyayi be mapped directly to an AST? Can inflectional morphology replace traditional syntactical symbols? Sanskrit was arguably the first formally specified language — so why not a programming one?"

Currently researching formal grammar structures and lexical analysis approaches. Reading: Panini's Ashtadhyayi, ANTLR documentation, and Dragon Book.

Indian Anime

Concept
Visual Storytelling / Animation Pipeline
What I'm Figuring Out

"What does a distinctively Indian visual animation style look like, wholly distinct from Western and Japanese tropes? How can classical Pattachitra and Madhubani motifs be integrated into modern cel-shaded pipelines without becoming pastiche?"

Gathering reference materials and drafting preliminary character style guides. Exploring Blender and Krita for a prototype short.

Personal OS in Sanskrit

Concept
Systems Architecture / CLI Design
What I'm Figuring Out

"Designing a command-line interface where commands are structured as Sanskrit sutras. How do we build a terminal emulator that natively supports Devanagari ligatures efficiently? What would a file system look like whose hierarchy is modelled on the Vedic knowledge classification system?"

Exploring custom font rendering engines, terminal frameworks, and the philosophical underpinnings of knowledge categorisation in Indian epistemology.
